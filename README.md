# Predictive Modeling of Short-Term Stock Returns

## Executive Summary

This project investigates whether machine learning models can predict short-term stock returns using a combination of technical indicators and engineered features derived from historical 
price and volume data. A diversified set of large-cap U.S. equities was analyzed, and features such as momentum, volatility, and volume anomalies were constructed.

Multiple models were evaluated, including Ordinary Least Squares (OLS), Ridge regression, Lasso regression, Decision Trees, K-Nearest Neighbors (KNN), and time-series models (ARIMA and SARIMA).
Model performance was assessed using Mean Squared Error (MSE) and out-of-sample R².

Results show that predictive power for short-horizon equity returns remains limited, with R² values near zero across all cross-sectional models. The best-performing cross-sectional model was 
Ridge Regression (MSE = 0.001562, R² = 0.007319). However, time-series models—particularly ARIMA—achieved the lowest overall prediction error (MSE = 0.000488), suggesting that simple temporal 
structure may be as informative as feature-based approaches at short horizons.

---

## 1. Define the Problem Statement

Short-term stock return prediction is a challenging problem due to market efficiency, noise, and the influence of unpredictable external events. Traditional approaches rely heavily on either 
technical indicators or fundamental data, but it remains unclear whether these signals provide meaningful predictive power.

The goal of this project is to develop and evaluate a predictive modeling framework that estimates 5-day forward stock returns using engineered features, and to determine whether different 
model classes (linear, nonlinear, and time-series) extract useful predictive signals.

---

## 2. Model Outcomes or Predictions

- **Type of learning:** Supervised Learning  
- **Problem type:** Regression  
- **Target variable:** 5-day forward return  

The objective is to generate continuous predictions of future returns and compare model performance across different modeling approaches.

---

## 3. Data Acquisition

The dataset was constructed using financial market data retrieved via the yfinance API and includes:

- Daily stock price data (Open, High, Low, Close)  
- Trading volume  
- Derived technical indicators  

Features engineered from this data include:
- 1-day returns  
- 5-day returns  
- 10-day and 20-day rolling volatility  
- Volume z-scores  
- Momentum indicators  

The dataset spans multiple large-cap U.S. equities across different sectors, providing a diversified sample for modeling.

---

## 4. Data Preprocessing / Preparation

### a. Data Cleaning
- Removed missing values generated by rolling calculations  
- Ensured consistent time alignment across all features  
- Dropped observations with incomplete feature data  

### b. Train/Test Split
- Time-based split to avoid lookahead bias  
- Training data: prior to cutoff date  
- Testing data: after cutoff date  
- `.copy()` used to ensure safe transformations  

### c. Feature Engineering
- Rolling volatility measures (10-day, 20-day)  
- Lagged returns and momentum signals  
- Volume anomaly (z-score normalization)  

All features were standardized prior to model training.

---

## 5. Modeling

All models were trained using a **unified pipeline**, ensuring:
- identical feature sets  
- identical train/test splits  
- consistent evaluation metrics  

### Models Implemented

**Linear Models**
- OLS  
- Ridge (selected alpha = 10000.0)  
- Lasso (selected alpha = 0.0020236)  

**Nonlinear Models**
- Decision Tree (max_depth=3, min_samples_split=100, min_samples_leaf=10)  
- KNN (n_neighbors=30)  

**Time-Series Models**
- ARIMA  
- SARIMA  

### Validation and Tuning

- 5-fold cross-validation used for Ridge and Lasso  
- TimeSeriesSplit used for time-aware validation (CV MSE ≈ 0.00121)  
- GridSearchCV used for Decision Tree and KNN  

---

## 6. Model Evaluation

### Evaluation Metrics

- **Mean Squared Error (MSE)**  
- **R² Score**

MSE was selected as the primary metric because it directly measures prediction error magnitude and penalizes large deviations. R² was used to assess explanatory power.

---

## Model Results

### Cross-Sectional Models

| Model | MSE | R² |
|------|-----|----|
| Ridge | 0.001562 | 0.007319 |
| OLS | 0.001562 | 0.007249 |
| Lasso | 0.001572 | 0.000770 |
| Decision Tree | 0.001577 | -0.002163 |
| KNN | 0.001631 | -0.036445 |

- **Best Cross-Sectional Model:** Ridge Regression  

---

### Time-Series Models

| Model | MSE | R² |
|------|-----|----|
| ARIMA | 0.000488 | -0.000085 |
| SARIMA | 0.000506 | -0.037586 |

- **Best Time-Series Model:** ARIMA  

---

### Overall Comparison

- **Best Overall Model (by MSE):** ARIMA (0.000488)  
- **Runner-up:** SARIMA (0.000506)  
- **Best Supervised Model:** Ridge Regression  

---

## Interpretation

- Cross-sectional models show very low R² (~0.007), indicating minimal explanatory power  
- Regularization (Ridge) slightly improves stability over OLS  
- Nonlinear models do not significantly outperform linear models  
- Time-series models outperform in MSE, suggesting temporal persistence may be more informative than cross-sectional features  

These results are consistent with financial theory, where short-term returns are highly noisy and difficult to predict.

---

## Business Analysis (Real-World Interpretation)

From a non-technical perspective, these results show that predicting short-term stock returns is extremely difficult. Even the best-performing models explain less than 1% of return 
variation (R² ≈ 0.007), meaning most price movements are driven by unpredictable factors such as news, sentiment, or macroeconomic events.

However, this does not mean the models lack value. In financial markets, even very small predictive signals can be useful when applied at scale.

### What These Results Mean in Practice

- Individual stock predictions are **not highly reliable on their own**
- Models capture **small statistical patterns**, not strong signals
- Time-series results suggest that **short-term price patterns may persist slightly**

### How These Results Can Be Used

1. **Portfolio-Level Strategies**
   - Apply models across many stocks simultaneously
   - Small predictive signals can accumulate into meaningful returns when diversified

2. **Signal Ranking**
   - Use predictions to rank stocks rather than predict exact returns
   - Focus on relative performance (top vs. bottom signals)

3. **Risk Management**
   - Identify periods of higher uncertainty or volatility
   - Adjust exposure accordingly

4. **Framework for Future Models**
   - This modeling framework can be extended with additional data (macroeconomic, sentiment, etc.)
   - Provides a structured way to test new signals

### Key Takeaway

The primary value of this project is not high predictive accuracy, but the development of a **robust and reproducible modeling framework**. In real-world applications, these models would be 
combined with other signals and risk management strategies to build scalable investment systems.
